# Calls toolset

Calls, unified history, transcripts, QA, callbacks, and live control. Connect only this group with `https://app.famulor.io/mcp?toolsets=calls`.

This 2026-11-27 snapshot covers all 55 tools assigned to `calls` in the canonical 601-tool registry. The live MCP `tools/list` response is authoritative for arguments, current availability, annotations, and plan or role gating. Never invent fields from this catalog.

Toolsets limit discovery context; they do not grant access. OAuth/API scopes and workspace roles are enforced separately. The Effect column reflects MCP risk annotations: `Delete/destructive` also covers overwrites or changes that can remove data or safeguards.

**Caution:** Calls and live-call controls can incur charges or disrupt active conversations; history removal can permanently delete data. Confirm the exact call, recipient, and action before execution.
